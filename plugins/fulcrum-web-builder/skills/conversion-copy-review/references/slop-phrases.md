# Ban list: generic and AI-sounding marketing phrases

These phrases signal copy written without knowing the customer. They are not always wrong, but each one must earn its place with a specific fact. `scripts/copy_lint.py` reads the first column of every table in this file, so keep one phrase per row, in lower case.

## Empty verbs and hype

| Phrase | Why it fails | Write instead |
| --- | --- | --- |
| unlock | Vague promise, no mechanism | The specific result: "see every overdue job on one screen" |
| unleash | Hype | What changes for the reader |
| elevate | Means nothing measurable | The measurable change |
| empower | Abstract | What the reader can now do |
| supercharge | Hype | The speed-up with a number |
| revolutionise | Unprovable claim | What is different from the usual way |
| revolutionary | Unprovable claim | The concrete difference |
| transform your | Abstract | Before and after, concretely |
| take your business to the next level | Cliche | The next level, named |
| game-changer | Cliche | The change |
| game-changing | Cliche | The change |
| cutting-edge | Dated, unprovable | The capability itself |
| state-of-the-art | Unprovable | The capability itself |
| next-generation | Unprovable | What it does that older options do not |
| best-in-class | Comparative claim needing evidence | Evidence, or remove |
| world-class | Unprovable | Evidence, or remove |
| industry-leading | Comparative claim needing evidence | Evidence, or remove |
| leverage | Jargon for "use" | use |
| utilise | Jargon for "use" | use |
| harness the power | Filler | Say what it does |
| the power of | Filler | Say what it does |
| robust | Vague | What it withstands |
| powerful | Vague | What it can do |
| innovative | Self-awarded | Show the innovation |

## Fake intimacy and filler

| Phrase | Why it fails | Write instead |
| --- | --- | --- |
| passionate about | Unverifiable, about you not them | What you do for them |
| we pride ourselves | About you, not them | Evidence |
| tailored solutions | Generic | What is tailored and how |
| solutions | Hides what you sell | The product or service name |
| one-stop shop | Cliche | List the three things people buy together |
| peace of mind | Overused | The guarantee or the risk removed |
| dive in | Filler | Start |
| dive into | Filler | Read, explore, or the real action |
| delve | AI tell | Look at, explore |
| embark | AI tell | Start |
| journey | Overused | Process, project, or the steps |
| curated | Vague | Chosen by whom, on what basis |
| holistic | Vague | The parts covered |
| synergy | Jargon | The combined result |
| ecosystem | Jargon unless literal | The products that work together |
| robust solution | Double vague | The product and what it handles |
| whether you're a | Throat-clearing list | Pick the audience |
| it's not just | AI cadence ("It's not just X, it's Y") | State Y |
| imagine a world | Cliche opener | Show the outcome |
| say goodbye to | Cliche | "No more X" only if literally true; better, the new state |

## Weak calls to action

| Phrase | Why it fails | Write instead |
| --- | --- | --- |
| submit | Describes the form, not the outcome | "Get my quote", "Send my enquiry" |
| click here | Not descriptive, bad for accessibility | The destination or outcome |
| learn more | Vague when used as the only CTA | "See how quoting works" |
| get started | Ambiguous about what happens next | "Start a 14-day trial", "Book a 20-minute call" |
| sign up now | Pressure without benefit | The benefit of signing up |

## Claims that need evidence before use (Australian Consumer Law)

These can be misleading unless substantiated. Keep the evidence on file; the ACCC can require it.

| Phrase | Requirement |
| --- | --- |
| fastest | Comparable test data, date, conditions |
| cheapest | Current price comparison including all fees |
| lowest price | As above; keep it current |
| best | Objective basis or clearly puffery in context |
| no. 1 | Source, metric and date |
| #1 | Source, metric and date |
| guaranteed | Exact terms; cannot limit statutory consumer guarantees |
| free | Truly free, or the conditions stated clearly next to it |
| australian made | Must meet the country-of-origin rules |
| australian owned | Must be true of ownership |
| eco-friendly | Specific, substantiated environmental claim |
| sustainable | Specific, substantiated environmental claim |
| carbon neutral | Certification or method disclosed |
| clinically proven | Published evidence relevant to the claim |
| 100% | The measured basis |
| trusted by | Real, permitted customers; the number must be current |
