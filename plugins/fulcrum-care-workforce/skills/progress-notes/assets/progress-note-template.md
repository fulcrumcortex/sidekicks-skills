# Progress note templates

Choose one format per note. Keep the admin block on every note. Replace bracketed text; write `[not stated]` rather than guessing.

## Admin block (every note)

| Field | Value |
| --- | --- |
| Participant reference | [P-xxxx] |
| Session date | [YYYY-MM-DD] |
| Actual start and end | [HH:MM to HH:MM] |
| Location | [clinic / home / community / telehealth] |
| Service type | [therapy / support shift / home visit / phone call / team meeting] |
| Present | [participant; others by role only] |
| Provider travel | [minutes, or none, or not stated] |
| Non-face-to-face time | [minutes and activity, or none] |
| Cancellation or no-show | [none / cancelled at HH:MM on date / no-show] |
| Author and role | [name, role] |
| Written | [date and time; mark LATE ENTRY if not the session day] |

## Format A: SOAP (therapy and clinical sessions)

**S: Subjective (reported)**
- [What the participant said about how they are, in their words where it matters; attribute every statement]
- [What a family member or carer reported, identified by role]

**O: Objective (observed and measured)**
- [What was done in the session]
- [Measurements, counts, times, distances, scores from named tools]
- [Observed behaviour and context, described not labelled]

**A: Assessment (author's interpretation, only if the author stated it)**
- [Professional interpretation, linked to the observations above]

**P: Plan**
- [Next session focus]
- [Home practice or strategies agreed]
- [Referrals or liaison, with owner and due date]

## Format B: Goal-linked (NDIS capacity building)

| Plan goal | What we did | What was observed | Progress since last session |
| --- | --- | --- | --- |
| [Goal in participant's words] | [Activity] | [Facts] | [Change, or "not addressed this session"] |

Participant's view: [what they said about the session or their goals, attributed]

Next steps: [actions with owner and date]

## Format C: Shift note (support work)

- **Supports provided:** [personal care, meal preparation, community access, medication prompt as per plan, transport]
- **Activities and participation:** [what happened, in order]
- **Wellbeing observations:** [mood as described by participant or observed behaviour; eating, sleep if reported]
- **Health and safety:** [anything unusual, falls, injuries, property damage; or "nothing to report"]
- **Communication:** [messages from family or other providers, by role]
- **Handover for next worker:** [what they need to know]

## Incident flag block (only if triggered; place at the top)

> **Incident flag:** [one line naming the matching item from the incident checklist]. Follow your incident management process now. If anyone is in immediate danger, call 000 first. This note records facts only; the incident report is a separate record.

- [unclear words, missing times, statements that could not be placed]
