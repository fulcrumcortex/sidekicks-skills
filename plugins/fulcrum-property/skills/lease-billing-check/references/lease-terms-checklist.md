# Lease terms to extract

Record each term as: value, clause number, page, quoted operative words, and the document it came from (original lease, variation dated ..., option exercise notice). If a term is absent, write "not in lease" rather than leaving it blank.

## Parties and premises

- [ ] Landlord, tenant and any guarantor, exactly as named
- [ ] Premises description and lettable area (and whether it was remeasured)
- [ ] Permitted use; whether a retail lease regime applies (ask the user if unclear)
- [ ] State or territory

## Term and dates

- [ ] Lease commencement date
- [ ] Rent commencement date, if different (often after a fit-out or rent-free period)
- [ ] Expiry date
- [ ] Options: number, length, exercise window (earliest and latest dates), conditions (no breach, notice form)
- [ ] Holding-over terms (monthly tenancy, rent on holding over)

## Rent

- [ ] Starting rent and basis: annual, monthly, weekly, per square metre
- [ ] GST treatment: rent stated GST-exclusive or GST-inclusive
- [ ] Payment frequency, in advance or arrears, due day
- [ ] Pro-rating rule for part periods, if stated

## Reviews (one block per review date, including option terms)

- [ ] Review date
- [ ] Type: fixed percentage, CPI, market, fixed amount, or a combination ("greater of CPI and 3%")
- [ ] For CPI: the series named (for example All Groups, a named city or the weighted average of capitals), which quarters are compared, rounding
- [ ] Floor, cap, ratchet (rent cannot fall)
- [ ] Notice the landlord must give, and any time limit after which the review is lost or still applies
- [ ] Market review process: valuer appointment, dispute timetable

## Outgoings

- [ ] Recoverable outgoings listed (rates, water, insurance, management fees, cleaning, air conditioning, land tax)
- [ ] Tenant's proportion and how it is calculated
- [ ] Budget, monthly instalments, annual reconciliation timing
- [ ] Exclusions and caps

## Security

- [ ] Bond or security deposit amount and form (cash, bank guarantee, personal guarantee)
- [ ] Top-up requirement when rent increases
- [ ] Residential: lodgement with the state bond authority, and the state's limit on bond amount

## Incentives

- [ ] Rent-free or abated periods, with exact start and end dates
- [ ] Whether abatement covers rent only or also outgoings
- [ ] Fit-out contribution, and any clawback on early termination
- [ ] Whether incentives sit in a separate incentive deed (ask for it)

## Other charges

- [ ] Car parks, signage, storage licences
- [ ] Late payment interest rate and when it starts
- [ ] Make-good obligations (not billed, but note for the file)

## Residential-specific

- [ ] Weekly rent and payment method
- [ ] Rent increase clause and the notice the state requires
- [ ] Any agreed rent reduction (for example during repairs) and its end date
- [ ] Utilities the tenant pays and on what basis (separately metered, water usage)

## Before you finish extracting

- [ ] Every variation and option exercise has been applied in date order.
- [ ] Each review date in the full term, including option terms, is listed.
- [ ] Any term you could not find is written as "not in lease" and raised as a question.
