# Scoring rubric

Four dimensions, each scored 0 to 3. The default weights suit someone selling booking, reservation or guest-communication tools to independent operators. Change the weights (and, where noted, reverse the scale) to fit what is being sold, and write the change into the summary.

Every score needs evidence: what was observed, the URL and the date viewed. A blank score means "not found"; the script does not count it.

## 1. Booking system maturity (`booking`, default weight 2)

Scored as the size of the gap a booking or automation product could fill. If you are selling something else (for example linen services), reverse the scale or set the weight to 0.

| Score | Observed evidence |
| --- | --- |
| 3 | Bookings by phone or email only; no online booking on the website |
| 2 | Enquiry form or a basic request form, or bookings only through online travel agencies or dining platforms |
| 1 | Online booking engine on the website, but no visible confirmation, reminder or self-service change options |
| 0 | Integrated online booking with self-service changes, reminders and a guest portal or app |

## 2. Target-market fit (`market`, default weight 3)

How closely the business matches the ideal customer the user described.

| Score | Observed evidence |
| --- | --- |
| 3 | Explicit evidence of the target segment: a corporate rates page, a weddings or functions page, group bookings, conference rooms (as the ideal customer requires) |
| 2 | Indirect evidence: reviews or listings mention the segment, or the location strongly suggests it |
| 1 | Category fits but no segment evidence |
| 0 | Evidence the business serves a different segment, or is part of a chain with central purchasing when the ideal customer is independent |

## 3. Size (`size`, default weight 1)

Set bands from the ideal customer. Default bands for an independent-operator product:

| Score | Accommodation (rooms) | Restaurants and venues (seats or capacity) |
| --- | --- | --- |
| 3 | 20 to 80 | 60 to 200 |
| 2 | 10 to 19, or 81 to 150 | 30 to 59, or 201 to 400 |
| 1 | under 10, or over 150 | under 30, or over 400 |
| 0 | Size rules it out (for example a 600-room resort for a small-business product) | Same |

Use the business's own figures (About page, listing). Do not estimate from photos.

## 4. Recent activity signal (`signal`, default weight 1)

Evidence in the last 12 months that the business is changing or investing.

| Score | Observed evidence |
| --- | --- |
| 3 | New opening, change of ownership or management, or a renovation announced |
| 2 | Hiring front-office, reservations or events staff; new menu, new function packages |
| 1 | Active and current (recent posts, current menus or rates) with no change signal |
| 0 | Signs of closure or inactivity: "temporarily closed", outdated rates, dead links |

## Tiers

| Tier | Rule | Next step |
| --- | --- | --- |
| A | 70% or more of the maximum score | Personal outreach first |
| B | 45% to 69% | Include in a sequenced campaign |
| C | Below 45% | Keep for later or drop |
| HOLD | A score lacks evidence, an email lacks its source, or data is invalid | Fix before use |

## Evidence quality rules

- Prefer the business's own website, then official directories, then platform listings, then reviews.
- Evidence older than 12 months is flagged stale; re-check it before relying on it.
- If two sources conflict (40 rooms on the website, 32 on a listing), use the business's own site and note the conflict.
- Quote a short phrase from the page in the evidence column where it helps ("Book by phone: ...").

## Column guide for the template

| Column | Content |
| --- | --- |
| business_name | Trading name as shown on the business's own website |
| category | hotel, motel, resort, serviced apartments, restaurant, cafe, bar, event venue |
| website | Home page URL |
| phone_published, email_published | Only as published by the business |
| email_source_url | The page where that email address appears |
| rooms_or_seats | Number from the business's own figures |
| <dim>_score, <dim>_evidence, <dim>_url, <dim>_date | For booking, market, size and signal |
| sources | Other pages consulted, separated by a vertical bar with a space either side |
| researched_by, researched_on | Who gathered the row, and when |
