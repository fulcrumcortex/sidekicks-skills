# Prepare an editable CAD design brief

Identify the design purpose, site context, units, constraints and any supplied dimensions. Ask about missing dimensions that change feasibility rather than inventing a survey or building-code result. Mark assumptions and unknowns explicitly.

Describe the layout using editable elements such as walls, openings, slabs, roofs and stairs where the available CAD supports them. Separate fixed constraints from preferences, and consider circulation and adjacency before styling.

If connected modelling is available and authorised, work on a preserved copy or a recoverable project state. Inspect the current model before changing it. Make bounded changes and compare plan, 3D and section views from the same model. If tools are unavailable, provide the brief and manual steps instead of claiming a model was changed.

Check supplied dimensions, openings, object placement and the consistency of the saved result. Export only the formats the current studio actually supports, and verify the file or cloud-save confirmation. A generated concept image is not an editable CAD model.

Return the brief, assumptions, model/export link if created and the specific checks completed. Dimensions, structural design and approval documents require the appropriate qualified review before construction use.
