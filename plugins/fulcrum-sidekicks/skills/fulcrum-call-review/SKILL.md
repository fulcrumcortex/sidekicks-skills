# Review a call and its follow-through

Locate the call in the correct organisation using its ID, time and participant context. Retrieve only the transcript, summary, recording or tool events needed for the request. Respect recording access and avoid exporting unrelated personal information.

Read the relevant transcript passages instead of relying entirely on an automated score. Identify the caller's intent, the agent's answers, explicit commitments, unresolved questions and the observed disposition. Mark unclear transcription as uncertain.

Check any promised action in its destination: a sent SMS, confirmed booking or saved CRM activity. A spoken promise and a successful call status do not prove those actions completed. Use current timestamps and stable record links where possible.

Propose a specific next step with an owner. Update records or contact a person only when the user authorised that action. A review request alone does not authorise an outbound call.

If a tool timed out, reconcile its external result before retrying. Return a concise evidence-based summary, discrepancies, follow-up and any missing capture or integration evidence.
