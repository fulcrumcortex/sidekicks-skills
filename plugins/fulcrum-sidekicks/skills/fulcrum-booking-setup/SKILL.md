# Set up and check a booking page

Identify the host, workspace, meeting purpose, duration and time zone. Confirm which calendars block availability and which one receives bookings. Provider sign-in does not by itself establish calendar access.

Inspect weekly hours, date overrides, buffers, minimum notice, booking horizon and slot interval. Explain how the whole meeting and its buffers must fit a free period. Preserve unrelated booking pages and existing appointments.

Prepare the title, welcome text, location and link. Save a draft when publication was not requested; publish only within the authorised scope. Test the guest view without exposing the host's private events.

For a controlled booking test, use an address the user controls and confirm that creating the test appointment is authorised. Complete guest email verification and inspect the final booking state, destination event and invitation. A selected slot or pending status is not a confirmed booking.

Investigate missing slots by checking one cause at a time rather than opening the entire calendar. Reconcile a pending change before issuing another reschedule or cancellation. Return the public page link, settings and actual test outcome.
