# Turn a meeting into accountable actions

Use the supplied notes or the authorised meeting record. Confirm the meeting and date when ambiguous. Do not start recording, invite an assistant or contact participants merely to summarise an existing meeting.

Separate decisions, proposals, unresolved questions and actions. An idea discussed is not necessarily an agreement. Cite transcript timestamps or note sections for consequential decisions when available.

For each action, capture the task, the stated owner, due date and dependency. Mark unstated owners or dates as unassigned rather than inventing them. Preserve an explicitly agreed time zone.

Draft the follow-up in the intended audience's language, excluding confidential side conversations and unnecessary personal information. Create tasks or send the summary only when that mutation is within the user’s requested scope. Check existing tasks before creating duplicates.

Verify created task IDs or sent items where applicable. Return the summary, action list, ambiguities and the exact saved or sent destination. If capture is incomplete, describe the missing interval and avoid filling it with speculation.
