# Draft a private message

Use only the context the user supplied or explicitly authorised you to read. Identify the recipient and purpose without retrieving unrelated conversation history. Ask for a missing fact only when it changes the message.

Draft the minimum useful content in the requested tone. Avoid copying confidential information from another person or channel. Treat disappearing-message settings and discreet previews as product features, not guarantees that a recipient cannot retain information.

Keep contact details, private links and attachments out of a public sample. Never ask the user to paste encryption keys, recovery phrases or credentials into the draft or a reusable skill.

Return the draft with any factual uncertainty. Do not send, change privacy settings, export a chat or claim an integration exists merely because this skill mentions Kyphra. If sending is separately requested and a supported authorised tool is available, verify recipient and destination, then inspect the actual send outcome before retrying.

Use the [current product guide](https://kyphra.app/) for interface details. Discover the tools available in this environment; the skill itself supplies no credentials or integration.
