# Weekly review template

Use the owner's local time. About 35 lines.

```
Week ending <Fri d Mon> · review

LAST WEEK'S OUTCOMES
<Outcome 1> · <met | partly met | missed> · <one-line reason>
<Outcome 2> · ...
<Outcome 3> · ...

WINS
- <Win with number>
...

SLIPPED
- <Item> · <cause> · <recovery and date>
...

NUMBERS (this week / last week)
New leads <n>/<n> · Meetings <n>/<n> · Won <$>/<$>
Cash in <$>/<$> · Overdue <$>/<$>

NEXT WEEK: PICK 3 OUTCOMES
1. <Outcome> · why: <one line> · owner <name>
2. ...
3. ...
4. ...
5. ...
Reply with three numbers, or edit the wording.

NEXT WEEK'S CALENDAR
<Heavy days, missing focus time, prep gaps, DST changes>

Not included: <unavailable sources or incomplete days>
```
